# Predicting Electric Vehicle Purchases

Tabular binary-classification pipeline for the Kaggle Playground Series S6E9
competition: predict the probability of `Will_Buy_EV` for each `id`. The metric is ROC AUC.
The repository contains the `ev_purchase` Python package, CLI scripts, YAML configs,
and analysis/experiment notebooks (CatBoost, LightGBM, XGBoost, FT-Transformer, ensembles).

Competition: <https://www.kaggle.com/competitions/playground-series-s6e9>

## Installation

Requires Python 3.11 or 3.12 and [uv](https://docs.astral.sh/uv/).

```bash
uv sync            # runtime + dev dependencies from pyproject.toml / uv.lock
```

## Data

The data is **not** included. Accept the competition rules on Kaggle, download
`train.csv`, `test.csv` and `sample_submission.csv`, and place them in:

```text
data/playground-series-s6e9/
```

(paths are set in `configs/base.yaml`).

## Usage

All commands run from the repository root.

```bash
# Validate data and write the split manifest
uv run python scripts/prepare_data.py --config configs/base.yaml

# Repeated stratified CV training (add --smoke for a fast sample run)
uv run python scripts/train.py --config configs/experiments/003_catboost.yaml
#   optional: --split-manifest <path-to-manifest.parquet>

# Bounded hyperparameter search (Optuna)
uv run python scripts/tune.py --config configs/tuning/catboost.yaml --trials 20
#   optional: --smoke

# OOF-safe blending of tuned studies; writes the locked final config
uv run python scripts/ensemble.py --tuning-studies outputs/tuning/catboost_hpo outputs/tuning/lightgbm_hpo
#   optional: --dry-run, --output-dir, --grid-steps, --config-out

# Retrain the locked final policy on the full data and write a validated submission
uv run python scripts/predict.py --config configs/final.yaml
#   optional: --output-root <dir>, --debug
```

`scripts/run_*.py`, `scripts/generate_*.py` and `scripts/build_*.py` are
experiment, submission and notebook-generator helpers; inspect the relevant script
for its requirements before running it.

## Tests

```bash
uv run pytest                      # full suite
uv run pytest tests/test_metrics.py tests/test_package.py   # focused example
```

Some tests read the local competition data or locally generated `outputs/`
artifacts; they need the data above (and previously generated outputs) to pass.

## Notebooks

- `notebooks/01`–`05_*.ipynb`: data understanding, baselines and feature analysis,
  model analysis, advanced experiments, final results.
- `notebooks/kaggle_ev_purchase_*.ipynb`: self-contained Kaggle notebooks (diversity stack,
  encoded HPO, encoder gain, feature search and ensembling, FT-Transformer,
  LightGBM ablation/HPO/bagging, super ensemble). They are regenerated by the
  matching `scripts/build_*_notebook.py` scripts.

## Local artifacts

Not tracked (see `.gitignore`): `data/`, `outputs/`, `ensemble/`, `catboost_info/`,
`dist/`, virtual environments, caches, and local agent/workflow files.

## Limitations

- Results depend on the competition's synthetic data and on locally generated artifacts,
  so they are not reproducible from this repository alone.
- Final-policy configs (`configs/final.yaml`) reference local `outputs/` paths.
- Some experiments assume a GPU (e.g. FT-Transformer notebook).
